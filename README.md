# variant-pathogenicity-llm-eval
Zero-shot evaluation of Qwen3 LLMs on variant pathogenicity classification. Reproduces the LLM-only baseline from BioReason (Fallahpour et al., 2025) using textual metadata only—a stricter ablation than the paper's published results. Benchmarks across three variant-effect datasets: VE-Coding, VE-Non-SNV
